ACJ Travel — Backoffice de promociones

Acceso

Este panel guarda y publica los paquetes/promociones/novedades directamente en el repositorio AedanCoder02/acj-viajes a través de la API de GitHub. Necesitas un token de acceso personal (fine-grained) con permiso de lectura y escritura de "Contents" sobre ese repositorio únicamente.

El token se guarda solo en este navegador (localStorage) y nunca se sube al repositorio. Si usas un equipo compartido, usa "Olvidar token" al terminar.
